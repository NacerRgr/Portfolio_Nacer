# Portfolio | Mohamed Nacer Er-Ragragy

Personal portfolio site. React + TypeScript, built with Vite and Material UI.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run preview  # preview the production build locally
```

## Structure

- `src/data/cv.ts`: all content (profile, experience, skills, education, stats)
- `src/theme.ts`: palette, typography, and MUI component overrides
- `src/components/`: page sections
